1. Overview

How STATIM 2.0 test cases are organized and classified.

STATIM 2.0 maintains one master test repository. Every test case authored for the application lives in this single repository and is never duplicated across packs.

Test cases are classified into execution packs for QA, UAT, Regression and Automation, so the correct subset can be pulled for any given testing need without rewriting or copying test cases.

2. Execution Packs

Five packs cover every stage of STATIM 2.0 test execution.

Smoke

Critical application health checks. Runs after every deployment.

Core Regression

Critical business functionality. Runs for every release.

Full Regression

Complete regression suite. Runs before major releases or Go-Live.

UAT

Business validation. Executed by QA and Business users.

Automation

Automated execution of selected stable business scenarios.
